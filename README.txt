EXAMEN CIVIQUE PWA

Test local :
1. Ouvrir un terminal dans ce dossier.
2. Lancer : python -m http.server 8000
3. Ouvrir http://localhost:8000 dans le navigateur.

Important : ne pas ouvrir index.html par double-clic pour tester l'installation et le mode hors connexion. Un serveur HTTP/HTTPS est nécessaire.

Publication : déposer tous les fichiers sur GitHub Pages ou un autre hébergement HTTPS.
